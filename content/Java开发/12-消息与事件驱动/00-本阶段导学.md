## 端到端语义

“Exactly once”必须说明边界：broker 内事务、producer、consumer state 和外部数据库不是自动同一事务。现实系统通常以 at-least-once delivery + idempotent consumer + outbox 获得可解释结果。

## 验收

模拟 duplicate、out-of-order、consumer crash before/after ack、broker unavailable、poison message 和 backlog。记录 event id、aggregate version、attempt、DLQ reason 与业务结果。
