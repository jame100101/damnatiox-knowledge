# Java 开源项目统一源码研究模板

> **Freshness metadata**
> - `last_verified`: `2026-08-24`
> - `version_scope`: `repository snapshots verified 2026-08-24`
> - `source_type`: `official-repository`
> - `stability`: `fast-moving`

每篇统一记录 Repository、Commit/tag、Research date、Purpose、Architecture、Module map、Entry points、Request/data flow、Patterns worth learning、Patterns not to copy blindly、Version assumptions、Confirmed facts、Inference、Unknown。

源码研究先固定 commit，再从入口→边界→数据流→测试→运行证据逐层确认。README 是产品边界来源，但实现结论还需代码/测试；目录命名支持静态推断，但必须标为 INFERENCE。
