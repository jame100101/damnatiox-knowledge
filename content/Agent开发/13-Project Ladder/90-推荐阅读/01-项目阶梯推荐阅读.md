# 项目阶梯推荐阅读

- [Datawhale Agent Learning Hub](https://datawhalechina.github.io/Agent-Learning-Hub/)：完整 Learning Todo List 和 Project Ladder。
- [datawhalechina/hello-agents](https://github.com/datawhalechina/hello-agents)：中文 Agent 原理与实践教程。
- [learn-claude-code](https://github.com/shareAI-lab/learn-claude-code)：从零构建 coding agent Harness。
- [claw0](https://github.com/shareAI-lab/claw0)：渐进构建长运行 gateway。
- [NirDiamant/GenAI_Agents](https://github.com/NirDiamant/GenAI_Agents)：横向查看 ReAct、Plan-and-Execute 与 Multi-Agent。
- [agents-towards-production](https://github.com/NirDiamant/agents-towards-production)：生产化 Agent 工程组件。

建议每一级只增加一组核心能力，并保留上一级回归结果，避免同时引入模型、检索、Memory、多 Agent 和部署后难以定位问题。
