# 评测、可观测性与安全推荐阅读

- [OpenAI Evals](https://github.com/openai/evals)：可复现 eval 任务与评估框架。
- [OpenAI Agents SDK Tracing](https://openai.github.io/openai-agents-python/tracing/)：Agent、handoff、tool、guardrail 的 trace。
- [LangSmith Evaluation](https://docs.smith.langchain.com/evaluation)：数据集、实验、trace 与评测。
- [AgentBench](https://arxiv.org/abs/2308.03688)：多环境 Agent benchmark。
- [SWE-bench](https://www.swebench.com/)：真实 GitHub issue 修复评测。
- [OWASP Top 10 for LLM Applications](https://genai.owasp.org/llm-top-10/)：Prompt Injection、敏感信息和代理风险分类。

建议产出：至少 20 条固定 case 的 eval 表，记录期望、实际、失败分类、trace、成本和延迟，并接入回归执行。
