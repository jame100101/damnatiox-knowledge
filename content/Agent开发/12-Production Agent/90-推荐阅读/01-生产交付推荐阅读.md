# 生产交付推荐阅读

- [OpenAI：A practical guide to building agents](https://openai.com/business/guides-and-resources/a-practical-guide-to-building-ai-agents/)：从单 Agent、工具到 guardrail 和多 Agent 的落地框架。
- [OpenAI Agents SDK](https://openai.github.io/openai-agents-python/)：tool、handoff、session、guardrail、tracing。
- [LangGraph](https://github.com/langchain-ai/langgraph)：durable execution、state、checkpoint 与 human-in-the-loop。
- [SWE-agent](https://github.com/SWE-agent/SWE-agent)：软件工程 Agent 与 Agent-Computer Interface。
- [OpenHands](https://github.com/All-Hands-AI/OpenHands)：coding agent 的运行时、sandbox 和产品形态。
- [DeerFlow](https://github.com/bytedance/deer-flow)：长任务、sandbox、memory、skills、subagents 与产物交付。

建议产出：一个他人可 clone 运行的 Agent 项目，包含 README、`.env.example`、固定 Eval、trace、权限说明、部署和回滚步骤。
